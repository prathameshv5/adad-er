# AT-AD ER Project Memory Bank

## Project Overview
This is an Assistive Technology for Accessibility and Disability (AT-AD) database schema project that models a comprehensive platform connecting persons with disabilities (PwD), vendors, caregivers, donors, employers, and administrators.

## Core Purpose
The system facilitates:
- Product discovery and matching for persons with disabilities
- Multi-stakeholder ecosystem management
- Review and interaction systems
- Help and support resources
- Story sharing and community building

## Key Stakeholders
- **PwD (Persons with Disabilities)**: Primary beneficiaries seeking assistive technology
- **Vendors**: Companies providing assistive technology products
- **Caregivers**: Support persons for PwD users
- **Donors**: Individuals/organizations providing financial support
- **Employers**: Organizations seeking to hire PwD individuals
- **Admins**: Platform administrators managing the system

## Technical Implementation
- Database schema defined in Mermaid ER diagram format
- Interactive HTML visualization with zoom/pan capabilities
- Comprehensive relationship mapping between all entities
- Role-based access control architecture

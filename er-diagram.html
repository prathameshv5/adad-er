Database Schema Overview

User Management: Multi-role system supporting vendors, PwD (Persons with Disabilities), caregivers, donors, employers, and admins
Disability & Products: Disability-based categorization with many-to-many relationships between PwD-disabilities and products-subcategories
Interactions: Product interests, reviews, and replies system
Notifications: System-wide notification management
Help System: Categorized help articles and FAQs by role
Story System: Admin-created stories that PwD users can like
Key Features: Role-based access, document management, review system, and comprehensive user profiles
